## Overview

This repository hosts my personal portfolio — a dark, editorial-style single-page site built from scratch with vanilla HTML, CSS and JavaScript. It covers who I am, what I build, and how to reach me.

**Live:** [zhanimk.github.io/portfolio](https://zhanimk.github.io/portfolio/)

## Highlights

- **Zero dependencies** — every icon and image is embedded directly in the HTML as inline SVG / base64. Nothing loads from an external CDN, so the page renders instantly and never breaks due to a third-party outage.
- **Custom design system** — a dark navy palette, `Space Grotesk` + `Inter` + `JetBrains Mono` type stack, and a consistent editorial rhythm (numbered chapter dividers between every section).
- **Scroll-aware navigation** — the active section is tracked with `IntersectionObserver` and highlighted live in the nav bar, on both desktop and the mobile menu.
- **Fully responsive** — a dedicated mobile layout with a slide-down menu, resized type scale, and re-flowed grids, not just a squeezed desktop view.
- **Built for speed** — no frameworks, no bundler, no `node_modules`. One HTML file, deployed straight to GitHub Pages.

## Run it locally

No install, no build step — it's one HTML file.

```bash
git clone https://github.com/zhanimk/portfolio.git
cd portfolio
open index.html   # or just double-click it
```

## Deployment

Served as a static site via **GitHub Pages**, built from the `main` branch, root folder. Any push to `main` updates the live site within a minute or two.
